# Política de seguridad

Si encontrás una vulnerabilidad (ejecución de herramientas sin permiso, bypass del Permission Engine, fuga de secretos, prompt injection que logra acciones), **no abras un issue público**. Reportala por [GitHub Security Advisories](../../security/advisories/new) del repositorio.

Incluí: descripción, pasos para reproducir, impacto y versión/commit.
