# Toolbox

Utilidades chicas de JavaScript, sin dependencias. Node 22 o más nuevo.

## Funciones

- `capitalize(text)` (`src/strings.js`): pone en mayúscula la primera letra.
- `sumRange(from, to)` (`src/sum.js`): suma los enteros de `from` a `to`, ambos incluidos.

## Tests

```
node --test
```

Los tests van en `test/`, uno por módulo, con `node:test` y `node:assert/strict`.
